# Pena Detailing Solutions — Sample Website

This is a **free sample website** built for Pena Detailing Solutions by [Clementine Web Co.](https://clementinewebco.com), a small web design studio based in St. Petersburg, FL. It's not live yet and isn't an official Pena Detailing Solutions website, just a preview of what one could look like.

## What's in this repo
A simple, framework-free, multi-page website:
- `index.html` — home
- `services.html` — full service breakdown, pricing, and an instant estimate tool
- `gallery.html` — before/after (placeholder pending real photos/video)
- `about.html` — Sebastian's story, mobile-vs-shop comparison, service area
- `reviews.html` — all reviews
- `contact.html` — call/text CTA and quote-request form
- `styles.css` — all styling
- `script.js` — nav, scroll reveal, the instant estimate tool, and the quote-request form

No build tools, no installs, open `index.html` in any browser to view it, or visit the live preview at **https://dljackson97.github.io/pena-detailing/**.

## About the content
Business name, phone number, service area, pricing, and review ratings shown here are real, pulled from Pena Detailing's current site.
